# QualiaDB — Stub / Non-Functional Code Register

_Generated by audit sweep 2026-10. Tracks code that is advertised but not
functional, returns fabricated results, or is honest-but-incomplete.
Companion to `qualiadb-website-update.md`._

Severity legend:
- **FABRICATES** — returns made-up data where a real result is expected
  (worst: violates the project's own "never fabricate" rule).
- **FAILS-CLOSED** — errors honestly; missing functionality, not wrong answers.
- **DESIGN** — intentional capability gate (profile/feature/host contract);
  listed for completeness, not a defect.
- **SCAFFOLD** — structural placeholder acknowledged in comments; low risk
  but easy to overclaim.
