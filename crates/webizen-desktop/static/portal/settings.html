Two settings surfaces

  • This portal (8080) — browser-accessible; tray menu opens it. Edits AgentConfig and exposes studio /manifest + /telemetry.
  • Webizen Studio webview — full Dioxus app at route /settings inside the Tauri window (QPU, themes, telemetry hooks).
  • Graph daemon (4242) — Qualia loopback engine; Anatomy QApps and phone-console ICP attach here with qualia_token.

Local job queue API

  • GET /api/jobs — queue snapshot
  • POST /api/jobs — enqueue (ontology import, bundled seed, daemon reload, …)
  • POST /api/jobs/{id}/cancel — cancel queued or running job

Jobs persist under %LOCALAPPDATA%/Qualia/local-jobs.json and run one at a time.

Headless alternative

Without this desktop shell, run qualia-cli daemon start and qualia-cli service doctor — no system tray required.
