# settings Index

## Functionality Overview

Naturalised 0.0.28 setup and maintenance shell. It turns raw configuration into
searchable tasks, setup-health signals, local-model discovery/activation/probing,
accessible appearance presets, and routes to existing privacy, hardware, backup,
reachability, and advanced technical controls.

## File & Subdirectory Manifest

- `health.rs`: Human-readable readiness cards backed by the versioned agent QA snapshot.
- `host.rs`: Typed JSON bridge to native Tauri commands with truthful preview errors.
- `mod.rs`: Searchable settings information architecture, task panels, theme gallery,
  experience-mode switch, and composition of existing system tools.
- `model_setup.rs`: Local GGUF/P64 discovery and picking, HTTPS download, activation, and
  reversible private inference readiness probe.
- `types.rs`: Stable section taxonomy and versioned diagnostics DTOs.
