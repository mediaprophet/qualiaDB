# shared Index

## Functionality Overview

Reusable Wellfair presentation primitives for domain identity, sensitivity, provenance,
offline/sync state, and consent authoring.

## File & Subdirectory Manifest

- `consent_grant_editor.rs`: Shared consent-grant creation/editing control.
- `domain_chrome.rs`: Domain labels, honesty state, and consistent panel framing.
- `mod.rs`: Shared-component routing and exports.
- `offline_state.rs`: Offline/degraded state presentation.
- `provenance_trail.rs`: Human-readable provenance history.
- `sensitivity_badge.rs`: Public/restricted/secret sensitivity indicator.
- `sync_state.rs`: Reusable synchronisation status.
