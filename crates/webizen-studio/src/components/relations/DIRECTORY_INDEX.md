# relations Index

## Functionality Overview

Restores communications and social-web capability as one coherent Relations
surface. Naturalised mode exposes inbox, people, groups and commons, requests,
reception, and agreements; Advanced Technical mode adds transport truth and the
legacy low-level social tools without removing the natural destinations.

## File & Subdirectory Manifest

- `groups.rs`: Group conversation and cooperative-project discovery plus direct project creation.
- `mod.rs`: Relations shell, destination navigation, deep-link handoff, and existing-panel composition.
- `people.rs`: Contacts, peers, connection actions, directory tools, and Chora relationship context.
- `technical.rs`: Mesh/reachability/setup inspector with configured, reachable, authenticated,
  and synchronized states kept distinct.
- `types.rs`: Stable naturalised and advanced destination taxonomy with contract tests.
