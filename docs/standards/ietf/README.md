# WebCivics Internet-Drafts

These are **working documents**, not RFCs, not IETF Working Group drafts, and **not posted** to the IETF datatracker in this tree. Shipping a `-00` here does not publish it.

CSCP-12 (datatracker submit) remains a **human** action. CSCP-08 (MASQUE bound-UDP on the Internet) remains **blocked** on a named operator and a live inbound URL. See [CSCP-08-LOCAL-CHORES.md](./CSCP-08-LOCAL-CHORES.md).
