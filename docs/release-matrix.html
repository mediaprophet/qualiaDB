Three products. One local-first stack.
What 0.0.38 is for. What 0.0.37 was for stays in the archive.

Qualia is the semantic graph and in-process LLM. Webizen is the habitat a person lives in — desktop, ontology, anatomy, rights. Poet is the creative environment that hosts VibeScript. They share one 48-byte CRDT engine. This page is the product map: what each does, and how to run it.

Binaries and installers ship from GitHub Actions on tag v0.0.38 · all releases

Qualia

Graph engine + local LLM

Zero-copy 48-byte CRDT graph, SPARQL-style query, GGUF→P64, wgpu inference on the machine. The daemon on :4242 is the graph — not an LLM HTTP server. Token generation stays in-process; classified context never egresses.

  • Ingest, query, shader, and P64 convert from qualia-cli
  • Browser portal: viewport, logic, WASM-safe science
  • Playground: portal plus on-device LLM demo (path, TTFT, tok/s)
  • On-device LLM · WASM engine · API

Webizen

Habitat for living with meaning

Desktop shell, local daemon, ontology MCP, Wellfair anatomy, rights VM. Memory · Relations · Care · Practice · World · Instruments. Natural persons are not identity assets; instruments are not peers.

  • webizen-desktop — Tauri habitat (signed Windows NSIS, macOS, Linux)
  • webizen-studio — authoring and Wellfair panels
  • Ontology MCP — N3, Quin query, SHACL, modal kernels in a 640 KiB kernel
  • 3D anatomy · QDNF fabric · ontologies

Poet

Creative host for VibeScript

Closed 0.1 grammar, growing Host catalog (1,107 invoke ids, 105 families). Cells, signed modules, Cosmic geodesy, diagnose JSON. Four ops: parse, check, diagnose, capability.invoke.

  • poet-cli — tool-chest and manifolds
  • vibe — language engine and bytecode VM
  • vibe-wasm — in-browser parse / check / diagnose / invoke
  • Vibe hub · playground · showcase

What the browser downloads

Two budgets, two jobs

The ontology kernel stays small so MCP can load on a phone. Portal and playground carry science (and playground carries the on-device LLM), so they use the engine cap — 16 MiB raw / 4 MiB gzip.
