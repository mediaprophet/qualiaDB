What 0.0.41 is for. Unified volumes, Etalon GPU physics, and sovereign identity.

Qualia is the 48-byte semantic graph engine, .q42 v4 volume runtime, in-process LLM, and MCP server. Webizen is the sovereign habitat a person lives in — desktop stations, Four-Plane Identifier Fabric, QDNF 384-bit QSR networking, and Omni-Scale GIS. Poet is the creative environment hosting VibeScript (vibe-0.03), 10D scenes, and Etalon multi-physics simulation. They share one deterministic 48-byte NQuin CRDT engine.

Qualia

Graph engine + .q42 v4 + MCP

Zero-copy 48-byte CRDT graph with 5-field XOR parity, PCAT prose catalogue, namespaced Q42LEX v4, 256-bit CRT ExactnessProfile, P64 inference, and JSON-RPC 2.0 Model Context Protocol (qualia-mcp).

  • Playground: SPARQL/N3 compiler, SHACL validator, and on-device LLM

Webizen

What the browser downloads

Two budgets, two jobs

The ontology kernel stays compact (800 KiB raw / 260 KiB gzip) so MCP can load rapidly on mobile and edge devices. Portal and playground carry WebGPU rendering, scientific solvers, and the on-device LLM within the 16 MiB raw / 4 MiB gzip engine cap.
