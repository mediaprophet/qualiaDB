Qualia, Webizen, Poet.
What 0.0.37 ships.

Three products on one engine: Qualia is the local-first semantic graph and in-process LLM; Webizen is the habitat, ontology MCP, and desktop/studio shell; Poet is the creative environment that hosts VibeScript. This page is the artefact map — what each product does, and which binaries and WASM profiles belong to it.

Logs: SUMMARY.md · WASM gates · cross-platform · GitHub Releases

Qualia

Graph engine + local LLM

Zero-copy 48-byte CRDT graph, SPARQL-style query, GGUF→P64, wgpu inference. The daemon on :4242 is the graph — not an LLM HTTP server.

  • qualia-cli — ingest, query, shader, P64 convert
  • portal WASM — viewport, logic, WASM-safe science
  • playground WASM — portal + browser LLM demo
  • Online LLM demo · WASM engine

Webizen

Habitat for living with meaning

Desktop shell, local daemon, ontology MCP, Wellfair anatomy, rights VM. Natural persons are not identity assets; instruments are not peers.

  • webizen-desktop — Tauri habitat (Linux artefact; signed Windows/macOS from release-desktop.yml)
  • webizen-studio — authoring / Wellfair panels
  • ontology MCP — 640 KiB / 200 KiB gzip lite kernel
  • 3D anatomy · QDNF

Poet

Creative host for VibeScript

Closed 0.1 grammar, growing Host catalog (1,107 invoke ids, 105 families). Cells, signed modules, Cosmic geodesy, diagnose JSON.

  • poet-cli — tool-chest / manifolds
  • vibe — language engine + bytecode VM
  • vibe-wasm — in-browser parse / check / diagnose / invoke
  • Vibe hub · playground

WASM sizes · measured

Product budgets, not a single slim gate

Portal and playground carry science (and playground carries the browser LLM). They fail a 2.6 MiB / 800 KiB ontology-sized gate on purpose. They pass the 16 MiB / 4 MiB Pages sanity cap. Ontology MCP stays on its own Webizen budget.
