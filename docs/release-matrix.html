Three products. One local-first stack.
What 0.0.40 is for. Multi-physics, sovereign GIS, and living instruments.

Qualia is the semantic graph, in-process LLM, and MCP server. Webizen is the habitat a person lives in — desktop, geospatial streaming, ontology, anatomy, rights. Poet is the creative environment hosting VibeScript and multi-physics simulation. They share one 48-byte CRDT engine. This page is the product map: what each does, and how to run it.

Binaries and installers ship from GitHub Actions on tag v0.0.40.16 · all releases

Qualia

Graph engine + local LLM + MCP

Zero-copy 48-byte CRDT graph, SPARQL-style query, GGUF→P64, wgpu inference on the machine, and standards-compliant JSON-RPC 2.0 Model Context Protocol (qualia-mcp) exposing semantic graphs and simulation tools to AI agents.

  • Ingest, query, shader, and P64 convert from qualia-cli
  • Browser portal: viewport, logic, WASM-safe science
  • Playground: portal plus on-device LLM demo (path, TTFT, tok/s)
  • On-device LLM · WASM engine · API

Webizen

Habitat + Sovereign GIS

Desktop shell, local daemon, ontology MCP, Wellfair anatomy, and high-precision geospatial streaming (qualia-geospatial) with hydro-enforced GeoTIFF DEMs, Hilbert 3D indexing, and diachronic isogloss mapping.

  • webizen-desktop — Tauri habitat (signed Windows NSIS, macOS, Linux)
  • qualia-geospatial — GeoTIFF, Hilbert curve, WFS/WMS streaming
  • Ontology MCP — N3, Quin query, SHACL, modal kernels in an 800 KiB kernel
  • Spatial & GIS · 3D anatomy · QDNF fabric

Poet

Creative host + Multi-Physics

VibeScript language engine with value-producing if-else expressions, alongside qualia-sim 64 Hz multi-physics (geomechanics, space weather, fire ecology, 2D SWE hydrology, and flora biophysics).

  • qualia-sim — 64 Hz deterministic multi-physics simulation
  • vibe — language engine with value-producing if-else
  • vibe-wasm — in-browser parse / check / diagnose / invoke
  • Vibe hub · playground · showcase

What the browser downloads

Two budgets, two jobs

The ontology kernel stays small so MCP can load on a phone. Portal and playground carry science (and playground carries the on-device LLM), so they use the engine cap — 16 MiB raw / 4 MiB gzip.
