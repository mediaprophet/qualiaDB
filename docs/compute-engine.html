v0.0.41 Architecture: CPU Reference Solvers & Etalon GPU Certification (ETA-14, ETA-15, ETA-17)

For a quick overview: QualiaDB separates semantic authority and exact reference math (`qualia-core-db`) from reusable hardware acceleration (`etalon-*`). The interactive browser cards below run the deterministic CPU reference solvers directly in WebAssembly. On native desktop and WebGPU hardware lanes, etalon-wgsl-forge (bridged via qualia-core-db::wgsl_forge::etalon_bridge) compiles typed KernelSpec + Schedule intermediate representations into target shaders (WGSL, SPIR-V, HLSL, and MSL), validates every module through the Naga AST verifier, and certifies GPU dispatches against these CPU reference oracles:

  • Kernel & Tensor Oracle Certification (ETA-14): Dense GEMM/GEMV, double-single emulated df64, radix-2 FFT, and GQA transformer decode blocks are diffed against the independent CPU reference oracle under explicit ExactnessProfile bounds (`ADR 0003`).
  • Continuum & Electromagnetics Verification (ETA-15): etalon-sim 3D Yee-grid FDTD Maxwell solvers and 2D Shallow Water Equations enforce Courant–Friedrichs–Lewy (CFL) stability and discrete Poynting energy conservation.
  • 48-Byte NQuin Graph Sieve & Radix Sort Parity (ETA-17): etalon-nquin executes warp-transposed uvec4 predicate sieves and 8-pass LSD radix sorts on 48-byte NQuinWire records with zero mismatches against the CPU sort/sieve oracle.

See the WGSL Forge Architecture and v0.0.41 Release Overview for full hardware qualification details.

What runs here (CPU-exact, in-browser)

Dense linear algebra, statistics & hypothesis tests, symbolic algebra, special functions & number theory, arbitrary-precision exact arithmetic, SI units & dimensional analysis, Fourier / Laplace / Z transforms, graph reasoning, and cryptographic hashing (SHA-2 / SHA-3 / BLAKE3 / HKDF) — wrapping crate::solvers::* and the RustCrypto primitives, the wasm-clean layers. In the browser these execute the exact CPU reference floor (`ExactnessProfile::Exact` / `DeterministicApproximate`).

What runs on the 0.0.41 Etalon GPU & Native Engine

The 9 specialized domain libraries (finance, medical, chemistry, engineering, full ML), the advanced CAS (symbolic integration / limits / series / ODE), the pure-Rust etalon accelerator stack (etalon-wgsl-forge, etalon-sim, etalon-signal, etalon-tensor, etalon-nquin, etalon-agent), and key-generating cryptography run on the native / MCP engine (see the 0.0.41 Release Preview). Several already have live demos on the Sciences pages.
