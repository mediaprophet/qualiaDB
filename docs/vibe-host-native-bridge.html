VibeScript Execution Profiles & Host Native Bridge

vibe-host is the execution and capability adapter boundary for VibeScript (vibe-0.1 and vibe-0.03). Poet is a creative user interface that consumes that host boundary; it is not the host ABI itself. Every capability invocation declares its execution route, numerical exactness contract (ExactnessProfile), and failure semantics up front—never silently substituting a synthetic mock when a paired native capability is required.

1. Execution Modes & The vibe-host Boundary

You do not need a local native installation to explore VibeScript or Q42: the RDF → Q42 → Vibe browser demo, the Live Playground, and the Interactive Showcase run their standalone WASM surfaces directly in the browser via LocalHost. The native bridge exists only when a program deliberately invokes a paired native capability (such as persistent SLG graph mutations, hardware GPU/QPU dispatch, or local daemon storage).

The local QualiaDB daemon exposes GET /vibe/capabilities. Its versioned JSON response uses the qualia-vibe-bridge/1 protocol and makes the execution route explicit for each of the 105 capability families. The endpoint is open without a token only in daemon development mode; production requests require an X-Qualia-Token accepted by the local hardware-backed key vault.

Execution Mode Capability Route Semantics & Guarantee
standalone-wasm / exact In-process WASM (LocalHost) The loaded WebAssembly module performs the complete calculation locally inside the browser or WASI sandbox (e.g. Cosmic.* astrometry, LinearAlgebra.* small tensors, pure CompiledCell evaluation, and vibe::diagnose).
standalone-snapshot / isolated-snapshot In-memory .q42 / NQuin snapshot The WASM host evaluates queries and SHACL/deontic checks against an isolated in-memory graph snapshot loaded into the tab. HTTP Loopback Transport

Authenticated Browser-to-Daemon IPC

The primary browser transport is authenticated loopback HTTP (/query, /update, and /vibe/capabilities). A browser client probes only after an explicit user gesture, presents the X-Qualia-Token pairing header, and handles requests asynchronously via an async suspend/resume execution surface rather than blocking the synchronous Host trait.

WASI Adapter Family

Local CLI & Edge Runners

WASI transports form a distinct adapter family from browser WASM. A local WASI runner or embedded edge node communicates over framed stdio or a Unix-domain socket (UDS), whereas browser WASM strictly uses the authenticated loopback service.

Fail-Closed E300 Contract

Zero Silent Substitution

When a capability family requires native-bridge authority or leased hardware access that is not present in the current host profile, vibe-host returns a structured E300 capability-unavailable diagnostic with the exact Family.method ID.

2. ExactnessProfile (ADR 0003 Numerical & Replay Contract)

Across scientific computing, geometric predicates, cryptographic parity, and interactive 3D rendering, different workloads require fundamentally different numerical guarantees. Defined in ADR 0003 and enforced across the QualiaDB capability registry (`capability_manifests.rs`) and VibeScript host dispatch, ExactnessProfile classifies every kernel into one of four explicit tiers so callers and proof verifiers know whether an output is bit-identical, interval-certified, bounded-deterministic, or interactive-approximate:

ExactnessProfile Tier Mathematical & Bit-Level Contract Representative QualiaDB & VibeScript Workloads
Exact Bit-identical, zero-rounding-error arithmetic across all platforms (CPU, WASM, GPU). Uses rational/integer representations, Shewchuk adaptive expansion predicates, or the 256-bit 4-prime CRT cascade so signs, orientations, and modular reductions are mathematically exact. 2D/3D robust geometric orientation & in-circle/in-sphere predicates, BFV homomorphic encryption modular rings, NQuin XOR parity & Merkle roots, deontic/epistemic logic verdicts, and compile-time IDF-04 firewall checks.
CertifiedBand Guaranteed error enclosure $[v - \epsilon, v + \epsilon]$ or proven truncation tolerance. Adaptive quadrature or interval/ball arithmetic tracks error bounds and fails closed if the requested tolerance band cannot be certified within the iteration budget. Cosmic.comoving_distance_mpc (flat $\Lambda\text{CDM}$ 15-point Gauss–Kronrod $G_7/K_{15}$ quadrature with explicit error estimate), IAU 2006/2000B astrometric transforms, and certified PDE/ODE solvers.
DeterministicBounded Fixed reduction order, fixed iteration ceiling, and deterministic IEEE-754 floating-point schedule (no non-associative thread-race reductions). Replaying the same input snapshot and seed yields deterministic trajectories within bounded memory. 64 Hz etalon-sim XPBD continuum physics, EcoPunk 26.5 km watershed hydrology & FvCB photosynthesis, Hartree-Fock / DFT SCF convergence ($10^{-8}\text{ E}_{\text{h}}$), and CompiledCell reactive DAG evaluation.
InteractiveApproximate Throughput-prioritized real-time approximation for visual presentation, HUD overlays, and speculative preview passes. Never permitted to author authoritative graph truth, deontic permissions, or topological sign predicates. 10D volumetric raymarching preview shaders, bloom/depth post-processing, real-time audio wavefield spatialization, and interactive camera spring smoothing.

3. The 256-Bit 4-Prime CRT (Chinese Remainder Theorem) Cascade

Standard 64-bit IEEE-754 floats (`f64`) lose precision beyond 53bits of mantissa, causing catastrophic cancellation in determinant signs, high-degree polynomial evaluations, and lattice cryptography when coordinates span astronomical or sub-Planck ranges. Meanwhile, arbitrary-precision heap bigints (`BigInt`) violate QualiaDB's Tier-1 Zero-Heap rule and cannot coalesce on GPU workgroups or inside the 42 MiB Sentinel arena.

QualiaDB solves this across the native and WASM boundary with a stack-allocated, zero-heap 256-bit 4-Prime Chinese Remainder Theorem (CRT) Cascade:

Residue Number System (RNS)

Four Pairwise-Coprime 63-Bit NTT-Friendly Primes

Large integer and polynomial ring computations are projected into four independent 64-bit prime moduli $(p_0, p_1, p_2, p_3)$ whose product $M = p_0 p_1 p_2 p_3 > 2^{252}$ spans the full 256-bit dynamic range. Every addition, subtraction, and multiplication executes in parallel across the four lanes without inter-word carry propagation.

Garner Mixed-Radix Cascade

Deterministic 4-Word Reconstruction

When an exact sign, magnitude comparison, or canonical 256-bit digest is required, the 4-stage Garner mixed-radix CRT cascade reconstructs the unique signed integer in $(-M/2, M/2)$ using precomputed multiplicative inverses $c_{ij} = p_i^{-1} \bmod p_j$ in fixed `[u64; 4]` stack registers—zero heap allocations, constant branchless control flow.

Cross-Target Bit Identity

Unified Native, WASM & WGSL Verification

Because each RNS lane uses exact integer modular arithmetic and the Garner cascade follows a fixed 4-step sequence, `standalone-wasm` in the browser and `native-bridge` on x86_64/ARM64/WGSL produce bit-for-bit identical 256-bit outputs under ExactnessProfile::Exact.
