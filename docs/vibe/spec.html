Normative Extension A: Omni-Scale Coordinate System (OCS) & Cosmic Primitives (OCS-10–OCS-13)

The Omni-Scale Coordinate System (OCS) (`crates/vibe/src/cosmic/`) defines the normative spatial, relativistic, and cosmological coordinate semantics for VibeScript (`vibe-0.1` and `vibe-0.03`). It spans 15 hierarchical scale levels from `L-2` (Planck quantum foam, $10^{-35}\text{ m}$) through `L3` (planetary WGS84 geodesy) to `L12` (FLRW cosmological horizon, $10^{26}\text{ m}$).

A.2 USRI & 16-Byte CB-USRI Grounding (MSB=0 Context Tokens)

Every cosmic coordinate is canonically identified either by a textual Universal Spatial Reference Identifier (`urn:omni:v1:<level>:<realm-path>`) or by a 16-byte compact binary header (`CompactBinaryUsri` / `CB-USRI`). When stored in an `NQuin`, the `context` word carries a 56-bit FNV-1a realm hash in bits `[0..55]` with `MSB=0` (sensitivity class in bits `[56..63]`), while inline object tokens mask hashes to 60 bits (`MSB=0`) to preserve the `resolver.rs` type-tag invariant.
