Why VibeScript? A Semantic & Capability-Bounded Execution Layer

VibeScript is engineered for applications where data meaning, ontological provenance, capability authority, and deterministic replay are core architectural requirements rather than afterthoughts bolted onto untyped objects.

VibeScript (spanning the vibe-0.1 workshop/cell dialect and vibe-0.03 continuum/quantum kernel bindings) is the native scripting layer of QualiaDB and the Poet creative environment. It is a statically checked, capability-bounded language engineered with zero heap allocations in Tier-1 hot paths, first-class RDF 1.2 and SPARQL semantics, verifiable deontic/epistemic modalities, and a compile-time identifier firewall (IDF-04). Across the 105 capability families, 1,121 bound Family.method host operations (Cosmic.*, LinearAlgebra.*, Quantum.*, GraphDatabase.*, BotanicalAnatomy.*, …) bind explicitly through using Family; declarations and the four-operation vibe-host-0.1 ABI. Autonomous agents and IDE tools self-repair directly from structured vibe::diagnose(src) JSON diagnostics.

Role 01

Reactive Cell Graphs

Pure, high-frequency formulas driving desktop UI manifolds and QApps. Cells form dependency DAGs with bounded evaluation, compile-once handle reuse (CompiledCell), and strict cycle detection. The hot evaluator executes without heap allocations.

Role 02

Signed Agent Modules

Cryptographically signed programs that query and mutate 48-byte NQuin knowledge graphs. Every external capability (graph query, network pulse, sensor feed) requires an explicit using lease grant and execution route, allowing the host to deny or diagnose unavailable authority with E300.

Role 03

Deontic & Event Hooks

Deterministic lifecycle handlers such as on pulse:message(...) and on tick(). Obligations, permissions, and prohibitions evaluate directly against the QualiaDB deontic logic engine; host effects remain explicit rather than silently mocked in standalone browser targets.

Stack Bytecode VM

VBC1 stack-based bytecode compiler and VM with 41 core opcodes + 27 cosmic opcodes for instant zero-copy serialization and deterministic sandboxed execution.

🩺

Diagnose JSON

Agent loop is vibe::diagnose(src) → error_code, byte span, suggested_fix. Codes E001–E800. Invalid source is never executed.
