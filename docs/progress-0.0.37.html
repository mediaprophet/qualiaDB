What is real in 0.0.37

Implemented, not stubbed

Portal science. CAS, DFT, ODE, bioinformatics, and organic chemistry compile into --features portal and wasm-logic. Slim fail-closed math stubs are not the product.
Clinical VM. Framingham / CHA₂DS₂-VASc / SCORE2 read complete facts from arena Quins. Missing inputs fail closed. The engine does not invent patient values.
Shared WebGPU. Browser packages reuse one device. Graph accel GPU kernels compile with gpu-runtime; CPU floor remains when the adapter is absent.
SPARQL on WASM. External sort uses a bounded in-memory k-way merge. Query sampling is a public, caller-visible stride — not a silent cull.
Law packages. WASM verifies Ed25519 on the same signature_message() path as native.
Pages size gates. Portal and playground: 16 MiB / 4 MiB sanity cap. Ontology MCP: 640 KiB / 200 KiB product budget. Measured 0.0.37 artifacts pass the new gates and fail the old 2.6 MiB / 800 KiB cap.

Honest gaps

Not claimed

  • Signed Windows NSIS and macOS Metal installers are GitHub runner jobs with signing secrets — not produced on the Linux agent that cut this branch.
  • QDNF / QPR is native and in progress. It does not replace DNS/IP inside the browser demos, and it is not the mock packet table on Network Webizen.
  • Ontology MCP does not grow science or LLM to “save” Pages. That kernel stays the size-bounded MCP product.
  • Daemon, filesystem volumes, NVMe/ZNS/CSD, BLE mesh, and eBPF remain native-only.
