A network that does not borrow DNS to know a human.

QDNF is Qualia’s native networking model. Inside a QDNF realm it does not require ARP, IPv6 neighbour discovery, DHCP, DNS, ICANN names, BGP, or a mandatory cloud relay. The Qualia Peer Runtime (QPR) is the library over that fabric — the intended replacement for libp2p, not a wrapper around it.

Honest status: QPR is native and still being built on 0.0.38. This page is a map, not a live packet capture. Locators and DNS names are handles — never the human (NaturalAgent). Ordinary Internet stays a Legacy Internet Gateway. Public Internet relay / MASQUE evidence flags stay false until a second host dials a URL Timothy supplies (CSCP-08 chores wait on that). No invented ticks. The older Network Webizen screen still plays a mock table.

What the layers do

QLink
Cryptographic adjacency. Neighbours are proven, not guessed from ARP.
DNI
Self-certifying, expiring topological identifiers — locators / handles, not forever-who from a path.
QRoute
Intra-realm link state and inter-realm path vector.
QResolve
DID / content / resource resolution without DNS-as-who. Optional domain names remain handles only.
QPolicy
Consent, capability, deontic authorization.
QSession / QSync
Encrypted datagrams and streams; signed bounded Q42 / CRDT exchange.

What it is not

  • Not a browser libpcap. GitHub Pages cannot see your NIC.
  • Not identity. Locators, sessions, and instruments stay off the who-plane (Identifier Fabric). Handle revoke ≠ who-erase. Human ≠ legal “person” ≠ bot.
  • Not DNS-as-who. A lost domain must not erase a human from the fabric; domains are optional handles.
  • Not “Solid as the architecture.” Solid LDP remains a federated access surface; QDNF owns naming and routing.
  • Not finished. On 0.0.38: native QPR / CSCP local slices (loopback H2 Extended CONNECT, local WSS patterns, fail-closed decode) — still not a public relay claim. Measured completeness lives in the CSCP programme and honesty flags, not in this honeycomb.
