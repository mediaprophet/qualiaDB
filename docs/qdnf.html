A network that does not borrow DNS to know who you are.

QDNF is Qualia’s native networking model. Inside a QDNF realm it does not require ARP, IPv6 neighbour discovery, DHCP, DNS, ICANN names, BGP, or a mandatory cloud relay. The Qualia Peer Runtime (QPR) is the library over that fabric — the intended replacement for libp2p, not a wrapper around it.

Honest status: QPR is native and still being built. This page is a map of what landed on 0.0.38, not a live packet capture. The older Network Webizen screen plays a mock table.

What the layers do

QLink
Cryptographic adjacency. Neighbours are proven, not guessed from ARP.
DNI
Self-certifying, expiring topological identifiers — not forever-who from a path.
QRoute
Intra-realm link state and inter-realm path vector.
QResolve
DID / content / resource resolution without DNS.
QPolicy
Consent, capability, deontic authorization.
QSession / QSync
Encrypted datagrams and streams; signed bounded Q42 / CRDT exchange.

What it is not

  • Not a browser libpcap. GitHub Pages cannot see your NIC.
  • Not identity. Locators, sessions, and instruments stay off the who-plane (Identifier Fabric F6).
  • Not “Solid as the architecture.” Solid LDP remains a federated access surface; QDNF owns naming and routing.
  • Not finished. Wave work on 0.0.38 landed native QPR slices over local IPC. Measured completeness lives in the spec programme, not in this honeycomb.
