## Rustdoc version tags

- **Generated at CI:** `pages.yml` runs `cargo doc --no-deps -p qualia-core-db -p qualia-cli -p qualia-client-core` → `docs/rustdoc/` (not committed; version comes from each crate's `Cargo.toml`, currently **0.0.17**).
- **`ENGINE_VERSION` / `get_engine_version()`:** `env!("CARGO_PKG_VERSION")` in `qualia-core-db` — WASM and daemon report `0.0.17` after rebuild.
- **Static HTML badges:** run `python scripts/sync_docs_version.py` after a version bump.
