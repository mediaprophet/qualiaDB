QBDL · mixed HMC streaming over QDNF · in-tree source

Stream a mixed habitat, one admitted leaf at a time.

A QBDL-profile Hyper Media Container is the native mux for a living scene: geometry (.10d), knowledge (.q42), electromagnetic fields (.emf), acoustic containers (.qac), matter rasters (.m64), and neural weights (.p64) travel together under one governed session. The product is selective disclosure — planner plus service loop — over the Qualia Decentralized Network Fabric, not a silent container rewrite and not HLS/DASH.

Verification scope (2026-11-15): Protected-channel service I/O is cargo-proven in process (17/17 ProtectedSession). Mixed-HMC planner, EMF/QAC/P64 stream views, Q42 HTTP Range, WSS mixed transfer, and production write_leaf stage-drop are landed in source and await the next locked qualia-core-db --lib cargo pass. ZIP .hmc is a legacy document-archive profile and is not a streaming target. PhysicalNetwork two-host and browser/WASM mux remain later gates. This page showcases the work; it does not promote an unrun cargo log to a release claim.

Many entries per family. An HMC may hold several EMF volumes, several QAC takes, and several .10d scenes. EntryFamily is a per-entry tag, never a unique slot. Selection is scene or analysis intent over entry identities — optional time and region — not “the EMF file”.

Layer 1 · Plain-Language Overview

What a mixed HMC actually streams

A peer describes a candidate, pages its directory, selects the entries a scene needs, and opens only those leaves the grant authorizes. Shared dependencies are charged once by identity. Control messages are never starved. Ready live families (EMF, QAC, 10D) continue while heavier M64/P64 work waits its turn.

Admit, then tag

Family matches the bytes

Format admit runs before an entry is tagged Emf, Qac, TenD, Q42, M64, or P64. Unlabeled or unknown-critical blobs stay Opaque. Incomplete and Refused entries never disclose a leaf.

Governed disclosure

Grant, credit, then payload

A ProtectedSession binds the handshake transcript into AEAD additional data. Leaf credit is one-shot. WouldBlock drops the authority guard before retry. Native interchange is CBOR or exact-length binary; JSON is exceptional ingest only.

Three bearers, one body

Native, HTTP, WSS

Local IPC, HTTP/1.1 identity encoding with Q42 Range, and TLS WebSocket carry the same QBDL record bodies. HTTP headers are an adapter. Loopback HTTP is Component evidence; two-process framing is a Process fixture. PhysicalNetwork two-host stays false.

Architectural Non-Goals

What this stream is not

  • Not ZIP streaming: The ZIP document-archive .hmc profile is legacy. The platform is unreleased; that profile is not a streaming target. Filename .hmc is never sniffed as QBDL.
  • Not one-of-each: Review §6 “one of each family” is a minimum mixed-bundle fixture, not a uniqueness invariant.
  • Not HLS / DASH: Multiplexing belongs in the planner and typed metadata. The container wire does not need a rewrite for this track.
  • Not a browser mux yet: GitHub Pages documents the contract. Browser/WASM streaming remains a later gate.
  • Not PhysicalNetwork: Two-host public Internet and MASQUE stay false. WSS is a labelled Transition bearer (TlsWssTransitionV1).

Layer 3 · Protocol Mechanics

Frozen kinds, lifted pages, short write stages

The service IRI is q42:QBDLStream/1. Record prefix is 208 bytes. Descriptor pages use the full 65776-byte record budget so class 8/9 directories (up to 65536 bytes) fit; leaf records stay at 18137 bytes.

Describe & DescriptorPage

Kinds 1–12 stay frozen

DescribeClient binds a CandidateIdentity. Class 1 requests may carry total=0; class 6 header pages must be exactly 64 bytes; class 7 index may reach 8388608. Header validation forbids a zero descriptor, context, or transfer id.

recv_control is the 80-byte control path and refuses Describe; use recv_describe / recv_descriptor.

ProtectedSession

In-process 17/17, two-process framing fixture

Production I/O is ProtectedSession over ProtectedChannel. Session remains the framing fixture. Both implement public ServiceIo. Two-process evidence uses binary QBDL-PSK1 and is class Process, never PhysicalNetwork.

Associate the request independently of Credit. Issue credit after recheck and before LeafData. A second issue is Replay.

HTTP Range & WSS

Adapter headers, exact QBDL bodies

HTTP/1.1 identity encoding; multipart is refused. A 206 window must equal the requested inclusive range. Q42RangeVolume::open needs enough bytes — a truncated header or lex window fails closed.

WSS uses the existing WssBearer under Session. TLS is not post-quantum publisher authority. Loopback tests are Component evidence.

write_leaf & recover

Stage loans do not span wait

Production write_leaf takes TransferRuntime plus ticket, opens a short stage for prepare, drops it for wait, then a new short stage for commit. Crash tests keep the named WriteStep split path.

Recovery copies payload, proof, and checkpoint into CopiedLeafMaterial (Drop zeros) so verify/arm run after the source loan ends.
