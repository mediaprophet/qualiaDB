Honest progress — 0.0.26

This page is for operators and reviewers who need the truth, not a launch brochure. QualiaDB is the semantic engine; Webizen is the habitat product shell. Where we are not yet good enough for life-critical sole reliance, we say so.

What 0.0.26 is for

Move from “engineering dashboard” language (Talk / Keep / Reach) to life domains that match how people live: Memory · Relations · Care · Practice · World · Instruments. Dual computational (engine) vs presentation (render) layers; natural persons are not identity assets; investigators and instruments must not dump private vault content by default.

Design pack (in-repo plans, not all published on Pages): mindware strategy, integrated surface map, habitat swarm, prestige surfaces.

Not good enough yet (as sole system)

  • Desktop installers / signed updater CI is still hardening — do not treat a failed Actions run as a silent success.
  • Local LLM decode on large models is not yet competitive with specialised CUDA stacks for latency-critical use.
  • Do not use free-form generation alone for high-stakes legal, medical, or safety decisions.
  • Native mobile apps are out of product scope; phone = installable remote controller PWA only.
  • GitHub Pages environment previously allowed only main / 0.0.24 — 0.0.26 deploys need branch policy + content refresh.

What is real in 0.0.26

  • Entity-view kernel — entity_view/* + view_host session: observer fail-closed, rights filter, presentation levels, web locus / library project, Memory spatialize GPU path (view_render_memory_spatial), scene pick / select by URI.
  • Habitat shell (Webizen studio) — life-domain top bar and sidebar; Lived Memory as home; Care shell with grouped areas (Body · Rights · Life · Commons · Instruments); Relations hub with instrument honesty (models/agents are not peer persons).
  • Practice → Memory — project create/seed can auto-Remember into the Work lane of Lived Memory (soft-fail if vault locked); work board Remember handoff.
  • Remote controller — installable companion / remote-controller PWA surface for phone as controller, not a second OS dump target.
  • Engine base (carried forward) — 48-byte NQuin, 42 MB Sentinel, modalities (deontic, epistemic, LTL, ASP, …), native GGUF/P64 + wgpu inference, SPARQL/N3/SHACL paths, vision/audio crates, privacy BFV/DP.
