Human-centric networking verified layer by layer.

This is the authoritative 0.0.41 implementation and qualification record for the Qualia Decentralized Network Fabric (QDNF), the Qualia Peer Runtime (QPR), and the qualia-cscp control plane. It separates working in-tree cryptographic and routing engines from labelled Transition bearers, platform-dependent Qualification holds, and external Public-network and standards gates.

Present in 0.0.41: QDNF decouples human identity (Entity plane) from expiring network locators (Handle plane) and pairwise cryptographic channels (Instrument plane), ensuring .q42 knowledge synchronization does not depend on ICANN DNS, BGP, ARP, or cloud relays. NET-18 through NET-21, EVAL-22, did:qi, and CSCP run deterministically in tree; unexecuted hardware and public-Internet gates report false rather than simulated success.

Layer 2 · Protocol Architecture & Evidence Taxonomy

Four Non-Overlapping Qualification Classes

Class 1 · Implemented in tree

Local and in-tree evidence

  • QPR & Connection Manager: Supervised cell admission (admit.rs), generation-checked resource leases (ledger.rs, release_checked_bytes), non-wrapping cancellation epochs, and durable .q42 v4 chunk-to-SuperBlock replication.
  • CSCP v1 Control Plane (qualia-cscp): Bounded fail-closed TLV codec, private mailbox, lease accounting, receipt persistence, local bound-UDP, local rustls WSS ↔ QSession, DATAGRAM capsules, and loopback TLS HTTP/2 Extended CONNECT.
  • Implemented identity slice (did:qi): Bounded QCDE-1 signed documents with create, advance_generation, deactivate (TombstonePermanent), verify_relationship_distinct_from_person, and CscpMailbox binding.

Class 2 · Labelled Overlays

Transition bearers

  • WireGuard / SocialWebNet overlay: Admitted as an explicitly labelled IP transition bearer; never misclassified as a zero-IP native link.
  • TLS WebSocket (WSS) & HTTP/2 Extended CONNECT capsules: Provide encrypted tunnel transport across legacy networks without claiming public Internet MASQUE qualification.
  • Nym mixnet framing: Deterministic sphinx-style bounded QFrame encapsulation for metadata-resistant routing integration tests.
  • Strict non-laundering rule: Transition bearers do not become Native Independent merely by carrying a QFrame (no_proxy_launder).

Class 3 · Hardware & Kernel Boundaries

Qualification holds

  • AF_XDP & Raw Ethernet: open_af_xdp() returns PlatformUnsupported in unprivileged environments; umem_registered() == false and silent_zero_copy_fallback() == false.
  • Physical Energy Telemetry: Process RSS and NUMA locality are sampled in tree (cells/hardware.rs), while hardware RAPL joule counters remain held (idle_energy_measured() == false) without dedicated sensor access.
  • OS Process-Kill Durability: Deterministic tempfile crash-recovery pairs run in tree (disk_crash.rs), whereas kernel-level power-loss WAL certification remains an explicit qualification hold (os_process_kill_qualified() == false).

Class 4 · Multi-Host & Registry Boundaries

Public-network and standards gates

  • Building next — Public relay, Internet two-host, MASQUE, QUIC/noq: Requires a live two-host public Internet topology (CSCP-08 / CSCP-09). Until executed, public_relay_dialed() stays false.
  • W3C Registry Status: did:qi is an in-tree pairwise instrument method — Not a W3C DID Spec Registries entry and not a W3C Technical Report.
  • IETF Datatracker Gate (CSCP-12): draft-webcivics-cscp-00 is versioned in tree alongside qualia-cscp; external submission to the IETF Datatracker remains a separate human action.

Continuity & Plane Separation

A handle is not a human

DNI locators, DNS hostnames, relay hints, Nym addresses, and session endpoints sit on the Handle and Instrument planes. They never define a natural person on the Entity plane. Revoking or losing a handle closes or holds that network path without erasing the person, their did:webizen agreements, or their local .q42 knowledge volumes.

Through EVAL-22, every release qualification bundle aggregates Etalon oracle receipts, QDNF transport/routing receipts, and QualiaDB arena invariant receipts with explicit passed, failed, and unsupported counters — ensuring qualification holds and public-network gates remain transparent.
