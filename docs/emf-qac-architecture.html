EMF v4 & QAC v1 Cross-Workspace Architecture

Electromagnetic Field v4 (Q42EMF64) and Qualia Acoustic Container v1 (qac\0\0\0\0\0) establish a unified binary envelope across QualiaDB and Etalon. This architecture enforces strict custody/compute separation: QualiaDB owns immutable storage, TLV metadata graphs, SI dimensional algebra, byte-exact DICOM/sensor preservation, and HTTP range streaming; Etalon provides GPU/CPU Maxwell-Yee FDTD, elastodynamic wave solvers, spherical harmonic HOA DSP, and WGSL compute kernels.

Envelope: 128B Header + 128B Directory Root Commitment: BLAKE3-256 INDEX_DOMAIN Conformance: 15 Standards Families · 236 V01 Vectors

Etalon Workspace (C:/github/etalon)

  • etalon-sim (FDTD & Wave Solvers): 3D staggered Yee Maxwell FDTD, discrete Poynting energy balance, Virieux elastodynamics, Kramers-Kronig causal dispersion (Drude, Lorentz, Debye, Cole-Cole).

  • etalon-wgsl-forge (Certified GPU Shaders): WGSL compute shaders (acoustic_fdtd.rs, maxwell_yee.rs) enforcing bit-exact CPU-GPU numerical parity budgets.
  • etalon-sense-* & etalon-tensor: Real-time hardware acquisition drivers (core, NFC, SDR) bound to QualiaDB custody through qualia-etalon-sensing-bridge.

Section 3 — Producer/Consumer Cutover, Legacy Rejection & 236-Vector Qualification

Fail-closed migration rules, collision-free two-stage dispatch, and independent adversarial gate results.

236/236 Vectors Passing
Legacy UA4Q Rejection

Legacy UA4Q envelopes (magics [0x55, 0x41, 0x34, 0x51], versions 1..3, and .q4au dev suffixes) are strictly rejected on all production paths. Readers fail closed without allocating memory or synthesizing metadata.

EMF v1..v3 Bridge Policy

Legacy Q42EMF64 v1..v2 envelopes are strictly rejected. EMF v3 64-byte display bricks are supported via EmfContainerReader & portal_load_emf display bridge, while v4 powers full multi-mode scientific custody.

Two-Stage Disambiguation

Modes 0x0100..0x0107 are collision-free: Stage 1 branches on 8-byte magic (Q42EMF64 vs qac\0\0\0\0\0); Stage 2 verifies nonzero descriptor_id referencing domain TLV Schemas (103 vs 205..208).
