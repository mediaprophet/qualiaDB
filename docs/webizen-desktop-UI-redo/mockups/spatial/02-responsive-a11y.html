Accessibility checklist (shell chrome)

  • Favorites and constellation tiles are labelled text, not icon-only essentials
  • :focus-visible rings on interactive controls
  • Contrast: ink on deep navy; Live/Planned pills with text + color
  • prefers-reduced-motion disables 3D motion flourishes
  • Keyboard: Tab order Talk → volumes → constellation → orbit
