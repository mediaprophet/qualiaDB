# QBS-08 bounded transfer runtime contract

2026-11-12. Implementation scope: new bundle/stream/runtime/ only; root routes modules and owns shared registries. This is resource/lifecycle admission, not descriptor authority, proof verification, durable storage or consumer-commit evidence. No wire tags, global parent ceilings or parent runtime implementations change.

The constructor borrows the **existing canonical** ReservationLedger, LeaseTable, OperationTable and FairScheduler mutably for its lifetime, and an existing ResourceGovernor immutably. It never creates a host ledger from copied caps. While this scoped adapter exists, embedding code must route those owners through it; it cannot also mutate the same parent owners. Parent tables remain responsible for all reservation/lease/operation tokens.

## Exact intended API

- ColdPlan::compile(&[TransferSpec]) -> Result<ColdPlan,QdnfError>: immutable caller-owned slice, at most64 rows, duplicate/nonzero logical operation IDs, finite deadlines, principal and non-Control class, nonzero work cost, policy generation and checked resource estimates. It creates no permission or proof handle.
- TransferRuntime::new(&mut ReservationLedger,&mut LeaseTable,&mut OperationTable,&mut FairScheduler,&ResourceGovernor,RuntimeProfile,ResourceBudget /*control reserve*/) -> Result<TransferRuntime,QdnfError>.
- admit(&ColdPlan,index,now,current_policy_generation) -> Result<TransferTicket,QdnfError>: validate before mutation; aggregate network/proof/storage/consumer/scratch budgets and actual ticket/credit metadata size, reserve through ResourceGovernor, acquire exclusive parent buffer lease, admit parent operation and enqueue fair work, then return the non-Copy ticket. On any rejection unwind all acquired parent ownership before returning.
- poll(now) -> Result<RuntimePoll,QdnfError>: use the canonical FairScheduler. Own ready work becomes Ready(CompletionKey); expired own work is canceled and reported; unrelated preexisting scheduler work is returned as External(PollOutcome), never silently dropped. Before mutation, admit refuses any generated schedule ID already present in the canonical scheduler. Only the exact active queued ScheduledWork record is classified as ours; every unmatched record returns External. No prefix classification is used.
- issue_credit(&TransferTicket,now,current_policy_generation) -> Result<RequestCredit,QdnfError>: only after Ready, only once, and only while policy/deadline/cancel state still matches. RequestCredit has private fields, is non-Copy/non-Clone and reveals operation, byte credit and CompletionKey; caller must additionally satisfy descriptor/Share/policy/service authority before sending a real request.
- cancel(&TransferTicket), expire(now), state(&TransferTicket): cancellation/timeout advances the parent cancel epoch and keeps charge and I/O lease held. No canceled output can regain readiness.
- complete_io(&mut TransferTicket,CompletionKey,now) -> Result<FinishOutcome,QdnfError>: owner/slot/generation fencing before mutation; only actual I/O completion or an unissued canceled request reaches this call. A still-queued request returns WouldBlock even after cancellation; poll must first consume its exact scheduler record. Release parent operation/lease and original ReservationHandle once, mark ticket spent, report Released/Cancelled/Expired/Revoked. Released means reclaimed I/O, never verified/consumed/settled work.
- close(): requires zero live transfers, completes the reserved control operation/lease and releases static/control parent reservation handles. Drop does not claim joined I/O; embedding code must retain the scoped owner and drain workers before close/drop.

RuntimeProfile supports **8 constrained /30 desktop** admitted transfers with 8MiB/32MiB aggregate windows. A64-row cold plan can therefore have pending unadmitted rows. The parent32-handle ledger actually reserves one static runtime charge and one dedicated control charge; bulk cannot take either. A dedicated control buffer lease/operation is held too. Existing parent users can reduce available capacity further; failure is an honest Capacity/BudgetExhausted result. The parent FairScheduler's8 scopes and per-class8 queues remain unchanged; scheduler capacity can reduce concurrent readiness. No64 simultaneous I/O claim.

The static charge uses size_of::<TransferRuntime>(); the per-transfer charge sums checked ResourceBudget values for network, proof, storage, consumer and scratch (including caller-selected crypto/worker-stack/persisted-buffer/extra queue scratch), then adds actual ticket/credit/key struct storage. Canonical parent table allocations must already be accounted by their host owner; they are borrowed rather than duplicated. All profile byte-window/parent admission checks precede credit. A nonzero explicit control reserve is held through teardown, and bulk always uses ResourceGovernor as Background/Interactive, never Control. This adapter accounts capacity; actual allocated buffers, storage writer exclusion and Etalon reservation tokens must be supplied by later integration owners and cannot be inferred from accounting alone.

Private-field tickets bind a process-local unique runtime owner, hot slot, nonwrapping generation and logical operation. Raw network integers cannot manufacture them. Copyable CompletionKey is a fenced callback identity, not a budget or permission token. It cannot release anything without the matching live non-Copy ticket. Cross-runtime, stale and duplicate completions refuse without touching live reservations. Slots are not reusable until completion. Parent cancellation alone never frees I/O storage.

Implementation files: mod.rs routing; plan.rs cold data/checked budgets; types.rs ticket/key/credit/states; owner.rs borrowed owner construction/close; transfer.rs admission/rollback/completion; dispatch.rs fair polling/credit/cancel/expiry; tests.rs meaningful lifecycle/failure fixtures (split before500 implementation lines). No builds by this worker; root owns the build slot and actual allocator positive-control harness.

Required tests: coupled reserve before credit; success conservation; all budget component overflow/rejection; expired admission; stale policy; queue/lease/op/ledger capacity rollback; duplicate operation; cancel/timeout retain lease+charge; late completion releases once; double completion; stale/cross-runtime key; explicit parent cancel_epoch exposure; no slot reuse until completion; same logical ID reused with stale queued scheduler record; unrelated canonical scheduler records returned; non-borrowable control reserve and constrained/desktop limits. Root must measure hot success/reject/cancel/late paths with actual allocator positive control. No source-only statement certifies those runs.

Queued cancellation refinement: queued is a separate retained flag. complete_io returns WouldBlock until poll consumes the exact owning ScheduledWork record, including for canceled requests. Thus slots cannot retire while an old own record remains in the canonical queue, and no tombstone/prefix classifier is necessary. Root owns the new read-only FairScheduler::contains_operation(OperationId)->bool prerequisite; admission checks it before any reservation mutation. Deliberately colliding and merely owner-prefix-matching preexisting records must be returned as External unchanged. pending_schedule_records counts only exact live queued records and close requires it to be zero.

Scoped integration limit: while the adapter lives, its mutable parent-owner borrows exclude unrelated direct mutation. External scheduler records are returned intact, but this adapter does not expose a general mutable-owner escape hatch; the main loop must dispatch work that does not need those owners, use an agreed owner-delegation facade, or drain/close the scope first. No fully concurrent unrelated-service host integration is claimed. The runtime is an explicit-close metadata owner: embedding code must keep it alive through actual worker drainage; dropping it early does not establish I/O teardown or release held parent charges. These lifecycle duties remain a QBS09 host integration requirement.
