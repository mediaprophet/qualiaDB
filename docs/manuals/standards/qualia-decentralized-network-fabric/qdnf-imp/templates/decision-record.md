- Memory/work/storage and failure/recovery consequences:
- Authority, privacy, crypto and compatibility consequences:
- Affected consumers, dependency changes and migration:
- Independent domain reviewers and objections resolved:
- Verification and reconsideration triggers:

For QNF adoption, compare exact-artifact preservation, bounded lookup, atomic publication,
recovery, storage and proof overhead against existing core formats. Record conditional child
checks explicitly. Do not freeze a new format simply because the project needs large data or
network services. For resource exceptions, retain ordinary-cell caps and reserve host control
capacity; an exception is scoped and supervised, not an implicit unlimited network cell.
