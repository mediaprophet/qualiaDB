Status vocabulary

Do not flatten the states

  • Implemented locally: working in-tree behaviour and its bounded evidence.
  • Transition: a labelled carrier that is useful but not Native Independent.
  • Held: an external qualification or authority is still required.
  • Not established: never infer it from a local test, mock, or static website.

Open gates remain open

Pages cannot be the network qualification.

GitHub Pages can describe and link the work. It cannot receive an inbound public session, serve as a MASQUE relay, establish two-host Internet evidence, submit an IETF draft, or perform independent cryptographic review. Those states remain explicit until their named evidence exists.
