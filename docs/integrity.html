Q42 v4 Volume Integrity

When you import an RDF ontology or dataset into a unified .q42 v4 volume, you can prove mathematically that every statement, namespace prefix, and prose annotation arrived intact. QualiaDB verifies integrity at four complementary levels: per-record 5-field NQuin parity, paged Q42LEX v4 dictionary round-trip, PCAT v1 prose digests, and full encoded-set equivalence against the original source file.

Layer 2 · Volume & Payload Architecture

Where Heavy Content Lives in .q42 v4

Graph structure stays in the 48-byte NQuin SuperBlocks of .q42 v4, protected by canonical 5-field XOR parity (subject ^ predicate ^ object ^ context ^ metadata) and indexed by BIDX, FIDX, and PIDX. Compact IRIs and literals up to 65,535 bytes resolve through the namespaced paged Q42LEX v4 (ADR 0015) dictionary.

PCAT v1 Out-of-Line Prose Catalogue (ADR 0014)

Signalled by header flag FLAG_PAYLOAD_CATALOGUE = 0x0080, oversized UTF-8 prose, treaty articles, and statutory commentary live in the PCAT v1 section. Each entry is attested by whole-section CRC-32C and per-item SHA-256 hashes so BIDX remains fast and unpolluted.

Transparent .hmc & .10d Media Packs

Binary media MIME types are rejected from PCAT and instead ship inside transparent .hmc (Hyper Media Container) bundles (whole-file CRC-32C + per-entry SHA-256, no opaque entry compression) alongside .10d, M64, EMF64, and P64 containers.

RDF / N3 / CBOR-LD Source→ import Complete (Q42 v4)→ Q42LEX v4 (ADR 0015)→ PCAT v1 (0x0080 · ADR 0014)→ Optional .hmc / .10d Pack

Layer 4 · Formal Equivalence & Edition Invariants

Verification Contracts & CLI Gates

1. Encoded-Set Proof

Use verify-graph --encoder=import to prove that the source RDF stream and the .q42 v4 volume encode the exact same quad set under Rio + q_hash. (verify-integrity is a fast XOR smoke check.)

2. Blank-Node Isomorphism

Graphs containing blank nodes pass encoded-fidelity with an explicit notice; pass --require-isomorphism when strict canonical blank-node bijection is required.

3. Edition Separation

Princeton WordNet (princeton.q42, ~127 MB) and OEWN 2025-plus are distinct lexical editions; cross-edition comparison requires --allow-cross-edition.
