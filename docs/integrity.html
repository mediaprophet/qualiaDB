Checked-in receipts

The Pages demo never downloads WordNet/OEWN. It shows small JSON receipts plus the Schema.org twin already under docs/data/schemaorg/ (~2 MB NT). Full OEWN 2025-plus (~227 MB TTL) is an operator-local library proof only. 

# User-scale twin (~2 MB): download Schema.org 30.0 + import + verify
.\scripts\verify_schemaorg_integrity.ps1

# Operator-only: full OEWN if you already have the TTL on disk (no download)
# Default path: C:\github\ontology\english-wordnet-2025-plus\...
.\scripts\verify_oewn_2025_plus.ps1

# Operator library matrix (sizes / support); does not fetch OEWN
.\scripts\verify_ontology_datasources.ps1
verify-integrity is an XOR smoke check only. Use verify-graph --encoder=import for encoded-set equivalence. Do not compare OEWN 2025-plus to Princeton princeton.q42 without --allow-cross-edition. Princeton (~127 MB .q42) is a release asset for the WordNet demo — a different edition from OEWN.
