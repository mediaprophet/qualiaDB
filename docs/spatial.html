Qualia vs Webizen — where the line is

Qualia (engine)
  • 48-byte NQuin graph, logic, SPARQL, WASM hot paths
  • Zero-heap evaluator loops, 42 MB SlgArena ceiling
  • Produces telemetry sources (memory, queries, LLM tokens)
  • 10D tensor semantics — what each dimension means
Webizen (shell + render)
  • webizen-web / webizen-render wgpu pipeline for browser & desktop
  • 10D projection — stack-fixed scene nodes, GPU uniforms, canvas layers
  • Consumes normalized 0–1 floats; shaders animate — CPU stays idle
  • Heap allowed in UI/DOM; not in Qualia evaluator hot paths

48-byte QualiaQuin Encoding

Spatial geometries are encoded as sequences of 48-byte QualiaQuins. Each vertex becomes a Quin with the position packed into the object field.

Vertex Quin Layout

subject: q_hash(geometry_id) predicate: q_hash("geo:hasVertex") object: (x << 40) | (y << 20) | z [60-bit packed] context: q_hash(graph_id) metadata: vertex_index parity: XOR fold

Face Quin Layout

subject: q_hash(geometry_id) predicate: q_hash("geo:hasFace") object: (v1 << 40) | (v2 << 20) | v3 [vertex indices] context: q_hash(graph_id) metadata: face_index parity: XOR fold

SPARQL Integration Example

Query 10D tensor data using SPARQL with Q42-specific predicates:

PREFIX q42: <http://qualia.db/q42#> PREFIX geo: <http://www.opengis.net/ont/geosparql#> SELECT ?concept ?q ?v ?w ?x ?y ?z ?t ?alpha ?mu ?sigma WHERE { ?concept a q42:SemanticConcept ; q42:quantumContext ?q ; q42:topologicalVariety ?v ; q42:manifoldIndex ?w ; q42:semanticX ?x ; q42:semanticY ?y ; q42:semanticZ ?z ; q42:temporalState ?t ; q42:amplitude ?alpha ; q42:modulation ?mu ; q42:spectralSignature ?sigma . # Filter by manifold (e.g., medical domain w=0) FILTER(?w = 0) # Spatial proximity query (Euclidean distance) FILTER( ((?x - 5.0) * (?x - 5.0) + (?y - 3.0) * (?y - 3.0) + (?z - 2.0) * (?z - 2.0)) < 1.0 ) # Temporal slice (provenance at specific time) FILTER(?t = 2024) } ORDER BY ?alpha LIMIT 100
