## Product cut (normative)

1. **One Poet, two hosts** — WASM and Desktop are hosts of the **same** human product dialect: **Ask · Keep · Talk**. Studio is the room those live in, not a peer product.
2. **Webizen Desktop is the shell** — settings, apps root, utilities, OS-like admin. Poet lives *inside* it; the shell does not replace Poet with a button wall.
3. **No thinner WASM path** — Desktop-only wins that already work for a person (e.g. radial wheel, Dual Studio, Keep care-look) **port into WASM**. Parallel chrome tracks are a FAIL.
4. **Reveal live capability** — if it is on live `ALL_BOUND` and a person can use it, chrome **shows** it under Ask · Keep · Talk. False held / buried Capability soup is a diagnose + chrome FAIL. **Held / not yet** only when the bind is really missing. Never “unavailable.”
5. **Human alone** — a person finishes the three loops without an agent remote-driving them. Agents assist; they do not Matrix the human.
