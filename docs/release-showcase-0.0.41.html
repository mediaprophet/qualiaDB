Release 0.0.41 Overview

Authoritative tour of the 0.0.41 release.

Release 0.0.41 unites the 29-crate qualiaDB semantic graph and habitat workspace, the pure-Rust etalon GPU/simulation/signal accelerator stack, and the vibe-script checked authoring environment. Together they deliver .q42 v4 Unified Volumes with 5-field NQuin XOR parity, the Four-Plane Identifier Fabric (Entity, Claim, Handle, Instrument), the Omni-Scale Coordinate System (OCS), 384-bit Qualia Source Routing (QSR), and cross-platform WebGPU volumetric rendering.

Each destination below identifies its runtime profile—in-browser WebAssembly, WebGPU hardware diagnostics, native CLI/daemon execution, or architectural specification. Consult the 0.0.41 Release Overview & Architecture Guide and the 0.0.41 Release Matrix for full subsystem qualification tables.
