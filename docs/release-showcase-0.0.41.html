From 0.0.40 to 0.0.41

A connected tour of the release.

Building on the 0.0.40 experiences, the 0.0.41 preview brings the wider ecosystem into view: semantic data and reasoning, scientific libraries, spatial tools, graphics infrastructure and application authoring. Modular libraries support these different surfaces; each destination below explains a specific part of that picture.

The links open existing demos and documentation. Their deployed artifacts can differ. A browser interaction, a native workflow and a roadmap entry each carry different evidence: use release progress and the release matrix to assess qualification.

Change the inputs. Inspect the math.

A workbench for geometric algebra, ODEs, thermodynamics, sequence alignment and chemistry.

Try this
