Architecture: LLM ↔ SPARQL closed loop

The pipeline runs entirely client-side via Qualia's native WASM + WebGPU stack (gguf_bridge → llm_agent Phase 8 decode). No third-party llama.cpp bindings. GGUF only — not LiteRT-LM.

If the SPARQL query fails validation, the error is fed back to the model for self-correction (up to 3 retries). Token streaming uses inferWasmAsync (yields to the event loop each GPU map_async, so the tab stays responsive) with inline Sentinel checks (0x99 anachronism byte).

COI note: The COI service worker at the top of this page injects Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp headers on reload, enabling SharedArrayBuffer for multi-threaded WASM inference.
