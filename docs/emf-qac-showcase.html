30 Authoritative Accept Vectors

  • All 8 canonical EMF v4 modes round-trip verified (0x0100..0x0107).
  • All 8 canonical QAC v1 modes verified with raw/continuous payloads.
  • Multi-entry deterministic directory ordering by (stream, tick, spatial, mode, desc).
  • Full index commitment verification under QUALIA-FIELD-INDEX-v1\0 domain.
  • DICOM Part 10 bit-exact roundtrip across 6 primary Transfer Syntaxes.
  • Shared AcquisitionView (Schema 6) and Derivation (Schema 7) bindings.

206 Fail-Closed Reject Vectors

  • Cross-family magic substitutions (e.g. Q4AU, Q42AC064 alias, BADMAGIC).
  • Corrupted Castagnoli CRC-32C in header (bytes 124..128) and directory entries.
  • Single-bit modifications in index BLAKE3 commitment (Error::IndexDigest).
  • Non-zero padding bytes in reserved regions (88..124, 78..80, 116..124).
  • Unsorted or duplicate directory entries violating strict monotonic order.
  • Stokes intensity norm violation ($Q^2 + U^2 + V^2 > I^2$).
  • Unknown critical fields/schemas (flag bit 0 set) without registered adapter.
