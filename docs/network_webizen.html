How It Works

Packet metadata is compiled to N-Triples patterns and evaluated against the Qualia-DB engine via localhost:4242/query or in-browser Rust WASM (qualia_core_db_bg.wasm). The Webizen VM compiles dynamic N3Logic rules into deterministic opcodes, evaluates deontic norm statuses, and verifies SuperBlock ECC parity.
