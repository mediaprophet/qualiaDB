## What 0.0.38 is for (habitat, not a new engine stamp)

0.0.37 shipped the full WASM-safe Qualia engine to GitHub Pages. 0.0.38 is the
habitat line on that engine: wait-honest chrome, humans-first Directory, human-alone
Talk / Mail, live Catalog Open pack, Continuity handle ≠ human, and Desktop Native
that prefers an already-healthy `:4242`.

### Held / not yet

Wait-honest chrome says **held / not yet** plus a short why. It does not paint
user-visible “unavailable” as broken theatre. Live `ALL_BOUND` binds must not
false-held.

### Directory, humans first

Palette `dir` / `contacts` / `address book` opens Talk → People. Humans list first.
Organizations are a legal-person who-kind. Tools last. Chatbot is a tool, not a peer.
No agent required.

### Talk / Mail, human-alone

Talk Send works without a local model. Missing instrument stays held / not yet.
Talk → Mail is the daily inbox. Receiver-down is held plus one start-receiver
control — not a red broken page. Poet Domain.info stays admin, not the daily path.

### Catalog Open pack, live bind

Desktop Catalog · Lexicon prefers HTTP `/invoke` `GraphDatabase.lexicon_manifest`
on Native Connected `:4242`. Empty or nonsense path stays **held / not yet — open
lexicon pack**.

### Continuity: handle ≠ human

Actor `did:qualia:…` is a handle / coord, never the human. Handle revoke
is not who-erase. Sanctuary Keep / volumes survive handle death.

### Desktop Native prefers `:4242`

A healthy Qualia daemon on the contract port is reused. Desktop does not spawn
`:4243` just because the bind probe sees `:4242` in use (tip `7a868ecd`).
