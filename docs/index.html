Webizen / QualiaDB 0.0.41

A local-first semantic graph engine, human-centric operating habitat, pure-Rust GPU/physics accelerator ecosystem, and checked authoring environment.

What it is: QualiaDB stores every semantic fact, rule, and spatial coordinate in a deterministic 48-byte NQuin record within a strict 42 MB hot-path memory ceiling. Webizen is the sovereign desktop and browser habitat designed around human life domains—where people, claims, network handles, and computational instruments remain cryptographically distinct. Etalon provides the pure-Rust WebGPU, volumetric rendering, 3D XPBD physics, and spatial audio stack, while VibeScript & Poet connect checked functional authoring directly to native and WebAssembly execution.

Why it exists: Modern software should protect human agency rather than extract attention or lock personal memory inside opaque cloud silos. Every computation in QualiaDB and Webizen is local-first, zero-allocation on hot paths, and verifiable through cryptographic provenance.
