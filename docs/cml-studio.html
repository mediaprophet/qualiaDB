CML Studio

Inspect and model the CML concept-graph. Drag nodes, draw connectors, then select a connector to assign its ontological predicate and a logic modality. The deontic lifecycle preview mirrors the engine's evaluate_deontic_contract; authoritative evaluation runs in Qualia-DB.

The three-layer model

TEXT

Verbatim source — immutable, recovered from the front-of-file lexicon. Unit of provenance.

CONCEPT

A node = a context hash that owns the sub-graph. cml:asserts → context = q_hash(concept).

LOGIC

Per-concept modality sub-graphs — any of the engine's logic libraries — masked on the concept hash.
